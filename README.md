# SpeakEasy - Aplicación Móvil de Aprendizaje de Idiomas

## Descripción

Este repositorio contiene la interfaz interactiva y la estructura base de **SpeakEasy**, una aplicación web/móvil diseñada para facilitar el aprendizaje de idiomas de forma intuitiva, personalizada y dinámica.

El objetivo de este prototipo es ofrecer un flujo continuo desde la personalización del usuario (nivel, metas diarias e idioma) hasta el aprendizaje práctico mediante lecciones interactivas, ejercicios de opción múltiple, traductor integrado y seguimiento de racha.

---

## Contenido

* **Pantalla de Bienvenida:** Presentación e inicio de la experiencia de usuario.
* **Selección de Idioma:** Configuración del idioma objetivo (Español, Inglés, Francés, Alemán).
* **Personalización del Perfil (Onboarding):** Captura de nombre, nivel actual (Principiante, Intermedio, Avanzado) y tiempo diario de estudio.
* **Dashboard / Inicio Principal:** Vista general del progreso, racha de días, lecciones recomendadas y accesos rápidos.
* **Módulo de Unidades y Lecciones:** Vista estructurada del avance por unidades y estados de lecciones (Completadas, En progreso, Bloqueadas).
* **Lección Interactiva:** Práctica de pronunciación (escucha y repetición) y vocabulario con soporte de audio.
* **Evaluación / Ejercicios:** Módulo práctico con preguntas interactiva y validación visual de respuestas.
* **Traductor Integrado:** Herramienta de traducción directa entre idiomas con historial reciente.
* **Perfil de Usuario:** Panel de gestión con métricas de progreso, racha y metas diarias.
